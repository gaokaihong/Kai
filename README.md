# Kai · AI 生图研究仓库

这个仓库专门用来做 AI 文生图（text-to-image）相关的调研与笔记。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `reports/` | 整理好的调研报告（Markdown），每份报告一个文件 |
| `research_notes/<报告名>/` | 对应报告的原始调研笔记与来源链接，供追溯和二次整理 |

## 已有报告

| 报告 | 主题 |
| --- | --- |
| [AI人像画风分类调研](reports/AI人像画风分类调研.md) | 非二次元 AI 人像到底有多少种画风，以及如何用多维坐标把它们分类（写实、3D、3D转2D、带立体感的 2D、绘画媒介等） |

## 约定

- 报告用简体中文撰写，画风名称、提示词关键词保留英文原文，方便直接拿去写 prompt。
- 每个结论尽量附来源链接，时效性强的内容（模型版本、平台功能）标注截至日期。
